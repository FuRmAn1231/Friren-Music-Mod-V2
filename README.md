# Frieren Music (NeoForge, Minecraft 1.21.1, client-only)

Замінює фонову музику Minecraft на OST Frieren (Evan Call): **спокій → бій → бос** з плавними переходами.

## Як зібрати
1. Створи репозиторій на GitHub і завантаж туди весь вміст цієї папки (разом з `.github`).
2. Вкладка **Actions** → "Build mod" → після зеленої галочки відкрий запуск → **Artifacts → frieren-music-mod** → всередині `frieren-music-1.0.0.jar`.
3. Встанови NeoForge 1.21.1, кинь jar у папку `mods`. Fabric API не потрібен.

## Логіка
- **Спокій**: треки по черзі (випадково, без повторів підряд), пауза між піснями 1,5 хв.
- **Бій**: починається, коли гравець наносить/отримує урон від ворожого чи нейтрального моба або іншого гравця (ручні тварини не рахуються). Спокійна музика стихає, бойова наростає.
  Закінчується через 15 с без урону, при смерті гравця або коли вбито всіх залучених ворогів. Бойова грає ще 5 с, потім стихає, а спокійна повертається (продовжує з того місця, де була).
- **Бос**: будь-який бос-бар вгорі екрана, зокрема з інших модів. Рейд-бар, Warden і Древній страж не рахуються. Для Дракона Краю першим грає Divine Revolte.
- **Гучність**: усе йде через повзунок «Music» лінійно (100% = 100%, 75% = 75%). Усі треки вирівняні до -18 LUFS, тож звучать однаково гучно.
- Головне меню лишається з ванільною музикою; у світі ванільна вимкнена.

## Налаштування
Усі часи — у `src/main/java/com/frierenmusic/Config.java`.

## Додати/замінити треки
Поклади файл у `src_audio/` з префіксом `calm_`, `combat_` або `boss_` (напр. `combat_zoltraak.mp3`), запусти `tools/convert_audio.sh` (потрібен ffmpeg) і закоміть. Код сам підхопить новий трек зі `sounds.json`.
Бракує: Journey of a Lifetime (calm), Zoltraak (combat), Qual (boss).

## Аудіо
OGG-файли лежать в `src/main/resources/assets/frierenmusic/sounds/music/` (розпакуй туди `2_audio_part1.zip` і `3_audio_part2.zip`). `sounds.json` уже в проєкті.

## Підтримка інших версій
Код написаний на Mojang-іменах; для іншої версії зміни `neo_version` у `gradle.properties` і, за потреби, назви класів.
